## Questions

Use **GitHub Discussions**:

- **Q&A** for how-to and troubleshooting;
- **Hardware** for Indy, SCSI, serial, Vino and GIO questions;
- **Research** for sources and design questions;
- **Show and tell** for demos and screenshots.

## Bugs and features

Use **GitHub Issues** with the matching form:

- bug report;
- feature request;
- compatibility bug (an IRIX binary that does not run);
- hardware task;
- clean-room concern.

## Security

Do not report vulnerabilities in public. See [SECURITY.md](SECURITY.md).

## Commercial support

There is none. IRIX 7 is a volunteer, clean-room project and is not affiliated with SGI or
any successor.
