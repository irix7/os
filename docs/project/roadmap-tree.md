# The Tree of IRIX 7

The Tree is the interactive, pan-and-zoom view of the milestone plan: the Indy
baseline and the single-node and two-node gates in the roots, the eight-node
and 128-node mesh gates on the trunk and scale branch, and the native
compatibility, display, runtime and scale-out tracks reaching towards v1.0.

[Open The Tree of IRIX 7](https://irix7.github.io/os/tree/)

It is generated from a single [`roadmap.json`](https://github.com/irix7/os/blob/main/tree/roadmap.json)
file, which follows the [milestone plan](milestones.md). Click any node for
the demo, acceptance criteria, dependencies, estimate and risks; use the search
to jump to a gate or track, or the rail along the bottom to move between M0 and
M10.

The tree is a map of dependencies, not a promise of dates. Its statuses are
updated when the repository actually moves.
